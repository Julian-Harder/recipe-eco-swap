## 3. Decisions and reasoning (details in LOG.md)

| # | Decision | Why |
|---|---|---|
| 1 | Match against Agribalyse ingredients, not our 41 categories | None of the hard cases (beef stock, peanut butter, courgette…) has a correct answer among 41 categories; all exist in Agribalyse |
| 2 | Drop finished products (ready meals, baby food, ice cream, cakes, biscuits/cereals, sweets); keep stock | The tool helps people **cook** with ingredients. *(Ian's call)* |
| 3 | Raw weights: drop a cooked food when a raw version exists | Recipes give raw weights; keeps the CO2 per kg consistent. *(Ian's call)* |
| 4 | Near duplicates are the same food unless calories differ by > 10% per 100 g | Practical definition of "same food" for scoring; calories from CIQUAL. *(Ian's call)* |
| 5 | Use a pre-trained embedding model, don't train one from scratch | Fastest route to a measurable AI component; fine-tuning on our own data is the next step. *(discussed with Ian)* |
| 6 | Tune only on a dev set; run the test set once at the end | A score tuned on the test set says nothing about new recipes (course: "do not change the evaluation set to make results look better") |
| 7 | Model `jonny9f/food_embeddings` + word overlap 0.3 + plain-ingredient penalty 0.1 + threshold 0.80 | Best on dev (33/48, fewest wrong answers). The food model alone gave +8 lines over MiniLM; the tweaks +2 (within noise) |
| 8 | Below the threshold the matcher abstains, and the UI asks the user (top-5 dropdown) | A wrong match silently corrupts the total; asking costs one click, and the top 5 holds the right food 94% of the time |
| 9 | Swaps stay on the 21 curated swaps; a food inherits a category's swaps if its name contains the category's keywords and its CO2 factor is within 25% | Parmesan gets the hard-cheese swaps; beef stock does not get the beef-mince ones |

## 5. Problems we ran into, and what we did

| Problem | What we did |
|---|---|
| The old test set flattered the keyword matcher (synonyms written for the same lines) | Replaced it with 48 harder lines; we picked the correct foods by text search **before** running any model |
| Iteration 1 (MiniLM) matched "minced beef" to "Poultry, minced meat": bolognese ≈ 3.9 kg instead of ≈ 15.5 | Built a dev set, compared 4 models on it; the food-specific model fixed it (score 1.00 for the beef) |
| Agribalyse has no calorie data, but the near-duplicate rule needs it | Joined CIQUAL (ANSES) on the shared food code; 51 of 1,615 foods still have no calories, so for them only an exact match counts |
| The ANSES CIQUAL website was down for maintenance (HTTP 503) | Used the CIQUAL 2025 + 2020 copies in Open Food Facts' GitHub repo |
| Agribalyse coverage gaps: no raw mushrooms, no minced pork or lamb, no black beans, no cottage cheese | Accepted as data limits; "200g mushrooms" became a test case where the right answer is to abstain |
| The "drop cooked" rule misses foods whose raw version has another name (e.g. "Green lentil, cooked" stays) | Logged as a known gap |
| pandas 3 turns `None` into `NaN` inside DataFrames (crashed `evaluate.py`) | Check with `pd.isna()` |
| The chosen model has very few users, and its card has no licence or training details; it is a 438 MB download | Acceptable for a course demo; flagged as a risk in LOG.md |
| On 48 lines, differences of 1–2 lines are noise | Said so explicitly; only the model choice (+8 lines) is a clear result |
| In this laptop's setup, the desktop app could not launch Streamlit from the Desktop folder (macOS permissions) | Local tooling issue only: ran `streamlit run` from a terminal instead |

## 6. Known limitations (still open)

- **Wrong matches the user has to fix:** "spaghetti" → spaghetti squash, "double cream" → a double-cream cheese, "courgettes" → courgette puree. In all three the right food is in the dropdown.
- **Abstentions:** aubergine, mince, scallions, lardons and most typos are flagged "please pick" (the right food is usually in the top 5).
- **Parser:** "1 head of brocoli" keeps "head of", so the model matches "head" (head cheese) and broccoli is not even in the top 5. "1 can tomatoes" is counted as 120 g instead of 400 g.
- **Swaps:** hand-curated (21), not context-aware, and savings assume the same weight of the replacement.
- **Open Food Facts product data** is still unused.
- **The threshold (0.80)** was chosen on 48 dev lines.
